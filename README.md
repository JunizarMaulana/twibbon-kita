# Twibbon Kita

Website pembuat twibbon berbasis browser. Pengguna dapat mengunggah foto, mengatur posisi, zoom dan rotasi, mengganti judul serta nama, lalu mengunduh hasil PNG 1080 × 1080 px.

## Menjalankan secara lokal

Buka `dist/index.html` langsung di browser, atau jalankan server statis dari folder proyek:

```bash
python -m http.server 4173 --directory dist
```

Kemudian buka `http://localhost:4173`.

## Privasi

Foto diproses sepenuhnya di browser dan tidak dikirim ke server.
